# Synthetic Analytics datasets

These JSON files are generated by `scripts/generate_analytics_samples.py`. They contain fictional security-test data only.

`expected-results.json` is the executable manifest used by the integration tests. It records the accepted risk levels, expected finding types, minimum finding count, tampering expectation, and data categories for every sample.

The large log fixtures intentionally contain sensitive-shaped values in the middle or at the end so the scanner and structural sampler cannot rely on the first characters of a document.
